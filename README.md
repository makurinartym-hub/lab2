Автор: Макурин Артём Сергеевич.

Готовый проект C++20: auto, лямбда-выражения, std::tuple,
constexpr/consteval, Google Test и GitHub Actions для Ubuntu и Windows.

## Быстрый запуск на Windows через VS Code и Dev Container

1. Распакуй архив. Открой в VS Code именно папку `lab2`, где находятся
   `CMakeLists.txt`, `.devcontainer` и `ip_filter.tsv`.
2. Запусти Docker Desktop. В VS Code установи расширение Dev Containers
   от Microsoft, если его ещё нет.
3. Нажми Ctrl+Shift+P → `Dev Containers: Reopen in Container`.
4. Дождись открытия контейнера. Для первого запуска нужен интернет:
   скачивается образ, устанавливаются инструменты и Google Test.
5. Выбери Terminal → New Terminal. Все дальнейшие команды вводи
   в терминале контейнера из папки проекта.
6. Выполни одну команду:

```bash
bash run.sh
```

Она настроит и соберёт проект, запустит 7 тестов, обработает выданный файл,
сохранит списки в `result.txt`, сообщение о поиске — в `search.txt`.
В терминале появятся результат поиска и первые 15 строк списка.

## Те же действия по отдельности

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
./build/ip_filter < ip_filter.tsv > result.txt 2> search.txt
cat search.txt
head -n 15 result.txt
```

После изменения кода достаточно повторить сборку и тесты:

```bash
cmake --build build --parallel 2
ctest --test-dir build --output-on-failure
```

Чтобы вывести всё непосредственно в терминал:

```bash
./build/ip_filter < ip_filter.tsv
```

Не запускай программу без перенаправления файла: она будет ждать ввода
адресов с клавиатуры. Эти команды рассчитаны на Linux-терминал контейнера.

## Что делает программа

IP-адрес — четыре числа от 0 до 255 через точки. Каждое число — октет.
Программа читает адрес из первого поля строки TSV. Остальные поля игнорирует.
Хранит адреса как кортежи четырёх целых чисел и сортирует по убыванию:
сначала сравнивает первый октет, затем при равенстве второй и так далее.

В стандартный вывод без разделителей поступают:
1. Все отсортированные адреса.
2. Адреса с первым октетом 1.
3. Адреса с первыми октетами 46 и 70.
4. Адреса, у которых хотя бы один октет равен 46.

Дубликаты из исходного файла сохраняются. Каждый входной адрес выводится
один раз в каждой подходящей выборке, даже если содержит несколько октетов 46.

Целевой адрес и результат поиска печатаются в stderr, который также виден
в терминале. Это позволяет оставить списки в stdout без разделителей.
Применение stderr здесь служит разделению вывода: «не найдено» не является
ошибкой программы.

## Вычисления при компиляции

`generate_ip` получает число 12345 типа std::uint32_t и выполняет
10 000 итераций алгоритма из задания. Результат: 60.137.213.242.
Промежуточное значение — std::uint32_t; беззнаковое переполнение допустимо.
Функция объявлена consteval, поэтому её вызов вычисляется при компиляции.
Результат сохраняется в inline constexpr-переменной target_ip.

constexpr-функция допускает вызов и при компиляции, и во время работы,
в зависимости от контекста. consteval требует вычисления при компиляции.
constexpr-переменная должна инициализироваться константным выражением.

## GitHub Actions

Создай репозиторий и отправь в него содержимое папки lab2. На верхнем уровне
репозитория должны лежать CMakeLists.txt и папка .github, а не ещё одна lab2.
В VS Code: Source Control → Initialize Repository → Stage All Changes →
Commit → Publish to GitHub. Не отправляй папку build.

Затем открой репозиторий → Actions → Build and tests.
Должны завершиться две задачи: ubuntu-latest и windows-latest.
Обе собирают проект и запускают тесты. Процесс запускается после каждого push.
Эти удалённые сборки требуется выполнить в твоём репозитории.

## Если возникла ошибка

- `CMakeLists.txt not found`: открой корень lab2 и выполняй команды оттуда.
- Ошибка скачивания Google Test: проверь доступ к GitHub и повтори настройку.
- `Virtualization support not detected`: Docker не готов к запуску контейнера;
  это отдельная проблема Windows/Docker, исходный код её не исправляет.
- Ошибка старого CMakeCache: удали только папку build этого проекта и
  повтори настройку. В архив build не включён.
- Программа ожидает ввод: используй команду с `< ip_filter.tsv`.
- Для обычной Windows-сборки вне контейнера нужны отдельно установленные
  CMake и компилятор C++20. Основной путь этой инструкции — Dev Container.
